# Security

`zatca/keys/` contains a **deliberately public**, sandbox-only demo key registered on ZATCA's
developer portal for a fictional store with ZATCA's sample VAT number. It cannot sign valid
production invoices. Please do not report it as a leaked secret.

To report a real vulnerability in this code, email **contact@ifynx.com** with details and steps
to reproduce. We aim to reply within 3 business days.
