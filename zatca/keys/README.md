# Demo keys (sandbox only)

`demo-private-key.pem` and `demo.csr` belong to a fictional EGS unit ("iFynx Demo Store",
VAT 399999999900003, ZATCA's own sample number) registered only on ZATCA's public
developer-portal sandbox with its public test OTP. The certificate ZATCA issues for it
is a sandbox certificate that is not valid for real invoices. The key is public on
purpose: the live demo at https://ifynx.com/zatca-e-invoicing-integration/ signs invoices in the visitor's browser with it.
Never reuse it for a real taxpayer.
